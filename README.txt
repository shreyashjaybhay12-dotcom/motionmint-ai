MOTIONMINT AI — FREE PROTOTYPE

Files:
- index.html: browser-based 3D explainer scene prototype.

How to use on Android:
1. Extract the ZIP using your Files app.
2. Open index.html in Chrome. If Android opens a text preview, use a browser-capable HTML preview app or upload the file to a free static host (for example GitHub Pages).
3. Keep internet access on because the prototype loads the free Three.js library from jsDelivr.
4. Enter a scene description and tap Build scene.
5. Drag to orbit, zoom, change camera views, play/pause the simple animation, add sample objects, save a scene JSON or screenshot.

Free-use note:
- No paid AI API, subscription, or API key is used.
- This is an early procedural prototype, not a general AI text-to-3D system.
- It supports a limited vocabulary of scene elements (house, bunker/shelter, underground, tunnel, road, bridge, car/vehicle, tree, arrow, pressure/weight).
- MP4 export, free-form model generation, a full object inspector, persistent projects, and complex scene planning are not implemented yet.
- A full text-to-3D movie creator is a larger project and cannot be promised as unlimited/fully automatic for free.
